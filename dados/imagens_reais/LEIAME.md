# Fotos reais

Coloque aqui fotos de material didático impresso (slides, apostilas, páginas de livro) junto com o texto correto de cada uma:

```
foto01.jpg
foto01.txt   <- o texto exatamente como aparece na foto
```

O arquivo `.txt` precisa ter o mesmo nome da imagem. Quebras de linha e espaços extras não importam, porque a avaliação normaliza os espaços.

Para avaliar:

```bash
python -m src.visao_computacional.experimento_ocr --pasta dados/imagens_reais
```

Use apenas material próprio ou com permissão e não inclua fotos com dados pessoais (nomes, matrículas, rostos).
